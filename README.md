# EL2012: Computer Organization and Architecture Lab

This repository contains all laboratory coursework and projects for the Fall 2026 semester[cite: 6]. 

## 📌 Course Information & Outcomes

* **University:** National University of Computer & Emerging Sciences (NUCES)[cite: 6].
* **Instructors:** Dr. Nasir Ali Shah and Engr. Fasih Ahmad[cite: 6].
* **Pre-requisites:** EL1005 Digital Logic Design (1 Credit Hour)[cite: 6].

### 🎯 Lab Learning Outcomes
By the end of this semester, the following objectives will be achieved:
1. Employ modern hardware/simulation tools in computer organization[cite: 6].
2. Implement modules of computer organization for a given functionality[cite: 6].
3. Attempt effectively as an individual or member of a team to fulfill the task as per the guidelines[cite: 6].

## 📅 Weekly Lab Schedule

| Lab | Topic |
| :--- | :--- |
| **1** | Apply modern simulation tool (Modelsim & Logisim) to explore basic processor components[cite: 6]. |
| **2** | Apply Verilog at gate and dataflow levels to implement combinational circuits[cite: 6]. |
| **3** | Apply behavioral-level Verilog to design and simulate combinational modules[cite: 6]. |
| **4-6** | Venus Simulator for Register Level Execution of RISC-V Arithmetic, Memory, Control, and Procedure Instructions[cite: 6]. |
| **7** | Implement an Arithmetic Logic Unit (ALU) and verify its functionality[cite: 6]. |
| **8** | Implement parameterized Verilog constructs to design scalable N-bit ALUs[cite: 6]. |
| **9** | Implement the program counter (PC) and instruction memory[cite: 6]. |
| **10** | Implement a register file to store and retrieve processor data efficiently[cite: 6]. |
| **11** | Integrate ALU, register file, and instruction components into a datapath[cite: 6]. |
| **12** | Implement the control unit to generate signals for the datapath[cite: 6]. |
| **13** | Integrate all components into a complete processor system capable of executing instructions[cite: 6]. |
